# Blurt-
A tiny, WIP programming language written in rust that contains a lexer, parser and interpreter. So far can only print.

-Printing in blurt.

Use `blurt` followed by text in double quotes:

//////////////////////
blurt "I like food";

blurt    "Ahoy mateys";

//////////////////////

- Every statement ends with a semicolon, like in Rust and C++.
- Spaces between `blurt` and the opening quote are optional, and any number is allowed.
- Text inside the quotes is printed exactly as written, including spaces.
- Strings can't contain a `"` yet.
